# Contributing to seculens

Thank you for your interest in contributing. Bug reports, enhancement requests, documentation fixes and pull requests are welcome.

## Reporting bugs and requesting enhancements

Use GitHub Issues: https://github.com/masahiroid/seculens/issues

Please include the version, your environment, the steps to reproduce, and what you expected to happen. Do not report security vulnerabilities in public issues; follow SECURITY.md instead.

## Contribution process

1. Fork the repository and create a branch from the default branch.
2. Make your change, keeping it focused on one topic.
3. Verify it (see below).
4. Open a pull request that explains what changed and why. Link the related issue if there is one.
5. The maintainer reviews the pull request. Changes may be requested before it is merged.

## Requirements for acceptable contributions

- Run the project's tests and linter as described in the README (typically `npm test` and `npm run lint`) and make sure they pass.
- New features and bug fixes add or update tests that cover the changed behavior and its failure cases.
- Follow the existing code style and structure of the repository.
- Update the README and other documentation when behavior changes. Keep English and Japanese documents consistent where both exist.
- Do not commit secrets, credentials or private data.
- Contributions are accepted under the repository's license.
